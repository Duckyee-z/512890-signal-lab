# 512890 买点研究室

华泰柏瑞中证红利低波动 ETF（512890）的日线买点核验与回测工具。纯静态网页，无第三方脚本、无账户持仓数据、无运行时服务端依赖。源码和 GitHub Pages 网站公开。

## 使用

- 信号工作台：前复权 OHLC 日线、MA20、A/B 首次触发标记；支持日期区间筛选、悬停、方向键逐日查看和点击记录定位。
- 历史记录：突破日期、B 冲高确认日期、剩余有效交易日及后 20 日收益，可导出 CSV。
- 资金回测：A、B 或合并信号；可调整初始资金、单边费率和滑点，查看账户净值及逐笔模拟交易。
- 规则与数据审计：完整定义、原始响应、请求链接、SHA256 及数据隔离记录。

## 自动行情更新与精度

GitHub Actions 在每个工作日北京时间 **16:37、18:37、21:37** 检查并发布收盘行情（UTC cron `37 8,10,13 * * 1-5`，运行可能延迟）。代码推送和手动运行也会更新。前端每5分钟检查最新发布的数据，支持手动刷新。

优先获取腾讯证券明确前复权 `qfqday`；失败时尝试东方财富明确前复权 `fqt=1`。每次使用单一来源的完整序列，重新计算 MA20 与 A/B，不混接不同复权基准。只纳入已收盘交易日（日内以北京时间15:15为保守截止），核验至少45根、OHLC、日期唯一和已知年份的交易日连续性。日历当前覆盖2024–2026年，之后需维护对应休市安排；页面会明确标出未独立核验的年份。

**小数位较少只作提示，保留来源原值正常参与计算。** 2026-10-26 原始前复权日线已重新纳入，原始收盘 `1.21` 不会被普通报价 `1.213` 替换。来源精度不构成排除K线的理由。

抓取或校验失败时保留上次有效数据及原始响应，记录尝试时间、成功时间与错误；日期不会倒退。页面明确标注来源、最新K线和更新状态。失败后的下一定时任务会再次尝试。`dist/source-market.json` 为本次有效来源原始响应，`dist/update-status.json` 为更新状态；`dist/source-tencent.json` 保留为最初快照的回归测试样本。

更新器不发送交易通知。前复权历史可能随分红修订，不是时点归档的实盘现金流账本。

## A/B 规则

MA20 包含当日收盘。共同突破：前一日收盘严格低于前一日 MA20，且当日收盘严格高于当日 MA20。突破后第 1–10 个真实交易日有效，包括第 10 日。等待期间收盘低于 MA20 则事件失效，相等不失效。每次突破 A/B 各最多触发一次；分别追踪，互不终止。

- A：突破后首次满足 `MA20 <= close <= 1.005 * MA20`。
- B：突破后的窗口内先出现 `close >= 1.015 * MA20`；严格晚于冲高日，再首次满足 A 的回踩区间且收盘低于前日收盘。

突破日不算回踩或 B 冲高确认日。以全量历史完成均线和事件重建后，才筛选展示区间。判定使用六位小数定点整数，不使用提前四舍五入的数值。后 20 日收益按下一交易日开盘至第 20 个交易日收盘计算，后续数据必须落在所选区间截止日以内。

## 模拟成交假设

每笔使用初始资金的 50%（含买入费用），最多同时两笔。信号收盘确认、下一交易日开盘模拟买入；持仓收盘相对入场上涨至少 5% 后，下一交易日开盘模拟卖出。允许小数份额，无止损，不建模最低佣金、手数、流动性或现金分红到账。末日待执行订单不成交，未平仓按收盘估值。区间从空仓开始。前复权收益近似不能等同实盘现金流。

## 验证

```sh
node --test tests/engine.test.mjs
node --check dist/app.js
```

12 项信号引擎测试和9项数据接入测试覆盖均线预热、严格突破、精确阈值、A/B 去重与独立追踪、第 10 日有效和第 11 日到期、跌破失效、未来数据隔离和次日成交。独立 Python Decimal 实现曾复核初始历史样本的 14 个信号一致（A 12 次、B 2 次）。

以保存的原始响应复现快照：`python scripts/prepare-data.py`。若输入新行情，先核验来源、复权、精度、最新日期及交易日历，再更新快照元数据与页面文案。

## GitHub Pages 部署

Settings → Pages → Source 选择 GitHub Actions，然后在 Actions 中运行 `Deploy 512890 signal lab`。工作流先测试，再仅上传 `dist/`。所有静态资源均使用相对路径，支持项目子路径。工作流会在 main 推送、定时和手动触发时自动更新并发布；数据缓存由 github-actions[bot] 提交，避免使用个人凭据。
